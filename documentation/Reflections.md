# Reflections

Comparing this exam to my first CA almost four years ago, a lot has changed. Some things have stayed the same. I still started with the design, this time in Figma (Adobe XD back then, but same same):

**Wireframe → detailed design → prototype → code → test → repeat**

The main defference is planning.
For this project, I put a lot more effort into planning and proper use of project management tools. I set up a timeline for (almost) everything I wanted to achieve, checked that I covered the brief, and made sure the API supported my extra ideas, for instance the dashboard summaries and host profiles.

Then I split the work into manageable work packages, called them "Planned Issues" and fed them into my GitHub project.

With that in place, I started designing. Sitemap and user flows first, then my style guide, and lastly the page mockups and prototype.

All before writing any code.

Point being, spending enough time planning this delivery left me with more time for coding and testing once I got going. Basic knowledge, I know. Still, there's something about learning it by doing, especially when you can see where the time went on earlier assignments.

The greatest advantage, from my perspective, is having a plan you can mess with. Once I had my issues and timeline in place, I could change things, add ideas or discard them without feeling the ground slipping from underneath me. And there were a few changes along the way.

Quite a few. Check my Ad-Hoc issues if you don't believe me.

I've also tried to bring feedback from earlier assignments into this project. Some of it I've probably handled well. Other bits, maybe less so.

One comment from JavaScript 1 has stuck with me throughout. My functions tried to solve too much, and I was encouraged to write several shorter functions with more focused tasks.

The result? A personal record of over 180 named functions in a single project. 🥳

I've learned a lot through my daily work this past year, and being able to bring that experience into this assignment has been kind of amusing. Usually, it's the things I learn through my studies that find their way into work.

Win-win!

Several evenings during this assignment were spent chatting with fellow student Annika Eldøy, testing, problem-solving and occasionally bitching about the whole thing. Having someone to spar with, and who could look at my work with fresh eyes and give honest feedback, made a difference when I'd been staring at the same page for too long.

She has been both moral support and a friendly user tester, and equal parts party-pooper and inspiration.

Thanks to Adrian De Souza as well, for my first ever proper student-to-teacher conversation about any of my assignments, for his tips and pointers, and for being responsible for these reflections (if you can call them that) being written at all.

Make of that what you will.
